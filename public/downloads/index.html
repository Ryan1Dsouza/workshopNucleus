+ControllerKitPhone-powered play

Your phone is the controller.

Install the app, start Bluetooth, then select your phone from the laptop. The game sends its controls to the app automatically.

Android

ControllerKit 2.0.7 switches to the selected Mario Kart and Fruit Ninja controls in one Bluetooth write.

Download Android APK ↓
  1. Allow your browser to install this downloaded app.
  2. Open ControllerKit and tap Start Bluetooth.
  3. Allow Nearby devices, then connect from the laptop.

iPhone

The native iPhone app uses the same interface and BLE protocol. Install a signed build from Xcode on a Mac.

iPhone setup instructions ↓
  1. Open the supplied Xcode project on a Mac.
  2. Select your signing team and connected iPhone.
  3. Build, install, then start Bluetooth in the app.

Network access downloads and updates the app. Button and motion input travel directly over Bluetooth.
Keep the laptop host open in Chrome or Edge. The two player slots pair independently.
